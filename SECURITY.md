# Security Policy

## Supported versions

Security fixes are provided for the latest released version of `lsusers`.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | Best effort |

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability.

Send a private report to `matheusabreu.dev@gmail.com` with the affected version, reproduction steps, potential impact, and relevant logs or proof of concept.

You should receive an acknowledgement within seven days. Please allow time for validation and remediation before public disclosure.
